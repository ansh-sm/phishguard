**PhishGuard SOC** is an enterprise-grade, modular email security and digital forensics engine designed to mirror the workflow of a Tier-2/Tier-3 Security Operations Center (SOC) incident responder:

$$\text{Ingest (.EML)} \longrightarrow \text{Deconstruct} \longrightarrow \text{Forensic Analysis} \longrightarrow \text{Threat Intel Enrichment} \longrightarrow \text{Scoring \& Verdict} \longrightarrow \text{SOC Playbook}$$

---

## 🚀 Key Architectural Capabilities

### 1. RFC 5322 & RFC 2045 Ingestion Engine
- Policy-driven, authentic parsing of message structures, headers, and multi-part trees (`multipart/alternative`, `multipart/mixed`, `multipart/related`).
- Recursive unpacking of nested forwarded messages (`message/rfc822`).
- Character encoding normalization with fallback decoders (UTF-8, Latin-1, CP1252).
- Automatic extraction and multi-hash calculation (MD5, SHA1, SHA256) for all attachments.

### 2. Header & Routing Forensics
- **Reverse Received Hop Traversal**: Reconstructs MTA transfer chains in chronological order (Sender ➔ Recipient MX), extracting transmitting hostnames, client IPs, protocols, and hop transit latency.
- **Network Boundary Classification**: Accurately classifies IPs as RFC 1918 (Private/Internal) vs. Public Internet egress IPs.
- **Authentication Analysis**: Comprehensive parsing of `Authentication-Results` and `Received-SPF` headers (SPF, DKIM, and DMARC enforcement policies).
- **Impersonation & Brand Protection**:
  - Levenshtein distance typosquatting detector against high-target enterprise brands (PayPal, Microsoft, Google, Apple, Amazon, Netflix, banks).
  - Unicode Homoglyph detection (Cyrillic/Greek lookalikes) and Punycode (`xn--`) domain spoofing.
  - Display name vs. Envelope address mismatch identification.
  - `Reply-To` and `Return-Path` disparity tracking.

### 3. URL Deception & De-obfuscation Engine
- Automatic URL defanging (`hxxp[s]://...`, `[.]`, `[@]`) and refanging for secure analyst triage.
- **Hyperlink Deception Checks**: Identifies discrepancies where anchor text visually displays a legitimate domain while the underlying `href` points to a credential harvesting server or IP host.
- **Obfuscation Detection**: Hex/percent decoding, IP-literal host detection, URL shortener unmasking, and credential-embedded syntax (`user:pass@host`).
- **Shannon Entropy Calculation**: Identifies high-entropy domains generated by Domain Generation Algorithms (DGA).

### 4. Quishing (QR Code Phishing) Detector
- Detects emerging Quishing attack vectors by correlating urgency prompts and MFA update lures with embedded QR code images in HTML DOM and attachments.

### 5. Attachment Deep Forensics
- **Magic Byte Inspection**: Verifies true file signatures against declared MIME types to catch disguised executables (`MZ` Windows PE files disguised as `.pdf`).
- **Double Extension Detection**: Identifies deceptive names such as `invoice.pdf.exe` or `statement.xlsx.vbs`.
- **Archive Inspection**: Inspects ZIP archive contents in-memory without detonation on disk.
- **Macro Scanning**: Scans Office documents for weaponized VBA macro streams (`vbaProject.bin`, `AutoOpen`, `Workbook_Open`).

### 6. Threat Intelligence Pipeline (Async & Resilient)
- Asynchronous lookups against **URLhaus (Abuse.ch)** and **PhishTank**.
- **Persistent SQLite Cache with TTL**: Prevents rate-limiting bottlenecks and enables instantaneous repeat lookups.
- **Air-Gapped / Offline Mode**: Complete analysis execution without external network calls via `--offline`.

### 7. Multi-Vector Scoring & Reporting
- Weighted heuristic matrix (0–100) aggregating Header, URL/Intel, Attachment, and Content risk vectors.
- Automated generation of a plain-English SOC analyst explanation and immediate containment playbook.
- Rich terminal UI, SIEM-compatible JSON (Splunk/Elastic/Sentinel), and self-contained executive HTML incident reports.

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/ansh-sm/phishguard.git
cd phishguard

# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\activate

# Install phishguard with dev dependencies
pip install -e ".[dev]"
```

## 💻 CLI Usage Guide

### 1. Scan a Single Email (.eml)
```bash
phishguard scan samples/phishing_account_alert.eml
```

### 2. Export Standalone HTML & SIEM JSON Reports
```bash
phishguard scan samples/phishing_account_alert.eml --html incident_report.html --json-out siem_event.json
```

### 3. Run in Air-Gapped / Offline Mode
```bash
phishguard scan samples/phishing_account_alert.eml --offline
```

### 4. Batch Scan a Directory of Emails
```bash
phishguard scan-dir samples/
```

### 5. Launch Interactive Web Dashboard & REST API
```bash
phishguard serve --host 127.0.0.1 --port 8000
# Open browser at http://127.0.0.1:8000 for interactive drag-and-drop triage
# Swagger API docs available at http://127.0.0.1:8000/docs
```

### 6. Threat Hunting: Export IOCs to CSV or OASIS STIX 2.1
```bash
# Export firewall blocklist CSV
phishguard export-iocs samples/phishing_account_alert.eml --format csv --output blocklist.csv

# Export OASIS STIX 2.1 Threat Intelligence Bundle
phishguard export-iocs samples/phishing_account_alert.eml --format stix --output threat_bundle.json
```
